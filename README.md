# PortSwigger Web Security Academy — Write-ups

My solutions and explanations for PortSwigger Academy labs.

Goal: build manual web security skills — not AI-assisted guessing. Every write-up explains the *why*, not just the payload.

## Progress
- [ ] SQL injection — Apprentice
- [ ] XSS — Apprentice
- [ ] CSRF — Apprentice
- [ ] Authentication — Apprentice

## Format per write-up
Each lab gets a `.md` file with:
1. **What the vulnerability is** (in plain English)
2. **How I found it** (the recon / manual testing step)
3. **The payload** (what I sent)
4. **Why it works** (mechanism — no hand-waving)
5. **How to fix it** (defensive coding)
